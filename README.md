# Мой персонаж

Telegram Mini App: обычный персонаж, повседневные дела и дневник реальных тренировок. Согласованная задумка записана в [CONCEPT.md](CONCEPT.md).

## Запуск

Нужен Node.js 22 или новее. Внешних пакетных зависимостей нет.

```sh
npm start
```

Сервер слушает порт 3000; другой порт: `PORT=3001 npm start`.

```sh
npm test
```

## Рабочий цикл

- «Сегодня»: разминка, душ, завтрак (по 10 XP), чтение (20 XP), бонус 20 XP за весь набор. Повторное нажатие не начисляет опыт; в новый местный календарный день дела доступны снова. Опыт не сгорает.
- «Персонаж»: человечек в обычной одежде, уровень и опыт. Каждые 100 XP — новый уровень. Без футбольной формы, позиций и искусственных характеристик.
- «Занятие»: бег (расстояние и/или время), футбол (время, необязательное расстояние), домашние упражнения (повторения каждого подхода), зал (группа мышц, упражнение, вес, подходы, повторения). Можно записать прошедшую дату.
- «История»: записи по датам, выполненные дела, бонусы и тренировки, фильтры.
- «Прогресс»: суммарный опыт, число занятий, записанные результаты отжиманий и подтягиваний (первая/последняя запись, лучший подход), суммарные километры бега.

Награды за занятие фиксированные: бег/футбол 50 XP, домашние упражнения 40 XP, зал 60 XP. Это предварительный игровой баланс, а не оценка здоровья и не рекомендация нагрузки. Объём тренировки не увеличивает её награду. Спортивные показатели не растут автоматически от начисления XP.

## Данные и Telegram

Данные хранятся в localStorage (`my-character-v2`) и не синхронизируются между устройствами. Старый накопленный опыт (`my-player-v1`) сохраняется при переходе, но прежние демонстрационные задания не превращаются в реальные занятия. Старые данные не удаляются. Очистка браузера удаляет сохранение.

Поддержка Telegram WebApp SDK: ready/expand, цвета, безопасные отступы, BackButton, виброотклик. В браузере приложение работает без SDK. Контракт SDK проверен с заглушкой; реальный запуск в Telegram/iPhone ещё не проверен. Для него нужны публичный HTTPS-адрес и Mini App у бота, настроенное через BotFather. Бот и размещение пока не настроены; секреты для локального запуска не нужны. Telegram initData не используется как авторизация — для аккаунтов нужна серверная проверка.

Начальные нормативы/тесты, пользовательские задания и варианты дня, квесты, повтор тренировки, Garmin, питание и чат пока не реализованы.
