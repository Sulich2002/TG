# Мой персонаж

Мобильное приложение с персонажем, ежедневными делами и дневником тренировок. Согласованная задумка — [CONCEPT.md](CONCEPT.md).

Опубликовано: https://sulich2002.github.io/TG/

## Разработка

Node.js 22+ (в CI — 24). Three.js 0.180.0 зафиксирован в package-lock.json, WebGL-модули раздаются вместе с сайтом, без CDN.

```sh
npm ci
npm start
```

`npm start` собирает локальные 3D-модули и статический сайт, затем запускает сервер на порту 3000. Другой порт: `PORT=3001 npm start`.

```sh
npm test
npm run build
```

17 доменных тестов проверяют опыт, уровни, старые записи, групповые занятия в зале, планы, темп и изменения телосложения. Браузерный сценарий дополнительно проверен в Chromium на ширинах 320/375/390/430, включая настоящий WebGL и вращение, формы, запись нескольких упражнений, сохранение и fallback без WebGL. Это не проверка на физическом iPhone или внутри Telegram.

## Механика версии 0.3

- Базовый день: разминка/душ/завтрак по 10 XP, чтение 20 XP, бонус за весь набор 20 XP. Повторное нажатие не начисляет опыт, пропуски не отнимают заработанное.
- Свои планы на сегодня: название и заранее выбранный размер — 5/15/30 XP. Не влияют на бонус за базовые дела. Незавершённый план можно удалить.
- Требования к уровням: 100, 125, 150, 175, 200 XP и далее +25 за каждый следующий уровень. Весь уже заработанный опыт сохраняется, номер уровня пересчитывается по новой шкале.
- Бег: 10 XP/км; если указано только время — 0.5 XP/мин. При наличии обоих показателей история выводит темп мин/км; время не начисляет награду второй раз.
- Домашние упражнения: отжимания/приседания 0.1 XP за повторение; подтягивания 0.5 XP за повторение. Повторения суммируются по подходам.
- Футбол: 1 XP/мин, расстояние необязательно и не даёт повторную награду.
- Зал: несколько групп мышц и упражнений за занятие; каждое содержит вес, число подходов и повторений. XP = 2 × подходы + вес × подходы × повторения / 100, суммируется по упражнениям. Это предварительный игровой баланс.
- Дробный опыт сохраняется с точностью до десятых. Предварительная награда показана до сохранения.
- Личные результаты: отжимания/подтягивания за подход, суммарные километры бега; для каждого упражнения в зале — наибольший записанный вес/объём и первый/последний вес. Это записи пользователя, не медицинская оценка.
- Персонаж: взрослый стилизованный человек с открытым торсом и в шортах; в начале небольшой живот, постепенно более спортивный силуэт к 20-му уровню. Реальная 3D-модель, поворот перетаскиванием/кнопками/клавишами. Когда экран скрыт, анимация останавливается. При недоступности WebGL остаётся подписанный упрощённый вид. Внешность — игровая награда, не отражение реального тела.

## Данные и публикация

localStorage `my-character-v2`, без общих аккаунтов и синхронизации. Схема расширена без удаления записей. Старые фиксированные награды за тренировки сохранены: только новые записи имеют правило `volume-v1`. Старые одиночные записи зала читаются как занятие с одним упражнением. Прежний опыт `my-player-v1` переносится без выдумывания истории.

GitHub Actions устанавливает фиксированные зависимости (`npm ci`), запускает тесты, собирает `_site` и публикует GitHub Pages. `node_modules`, `_site` и сгенерированный `vendor` не коммитятся. Инструкции — [DEPLOY.md](DEPLOY.md).

Telegram SDK: ready/expand, цвета, безопасные отступы, BackButton закрывает открытый диалог и возвращает на главный экран, виброотклик. В Telegram ещё не подключено к боту. `initDataUnsafe` не используется как авторизация.

Ссылкой можно поделиться, у каждого посетителя свой локальный дневник. Настоящий рейтинг друзей требует серверной базы, подтверждённых аккаунтов и общего API; GitHub Pages исполняет только статический клиент. Фиктивных участников и локального «общего» рейтинга нет. Garmin, питание, чат, нормативы и начальные тесты пока не реализованы.
