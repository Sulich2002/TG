# Мой персонаж

Мобильное приложение с персонажем, повседневными делами и дневником тренировок. Задумка — [CONCEPT.md](CONCEPT.md). Сайт: https://sulich2002.github.io/TG/

## Разработка

Node.js 22+ (CI — 24), фиксированный Three.js 0.180.0. Модули и анатомические модели поставляются с сайтом, без внешних CDN.

```sh
npm ci
npm start
```

`npm start` собирает `_site` и запускает порт 3000; другой порт: `PORT=3001 npm start`.

```sh
npm test
npm run build
```

29 тестов: опыт и уровни, миграция, планы, темп, тренировки/рекорды, профиль, календарные границы, серии дней, достижения и целостность моделей. Chromium дополнительно проверяет создание профиля, мужскую/женскую 3D-модель и вращение, календарь и фильтры, недельные объёмы, сохранение и все пять разделов на ширинах 320/375/390/430. Это не проверка на физическом iPhone или в реальном Telegram.

## Версия 0.4

При первом входе обязательно создаётся профиль: мужской/женский персонаж, имя, возраст, рост, вес. Данные хранятся отдельно в localStorage `my-character-profile-v1`; их редактирование не сбрасывает опыт или историю.

Модель — анатомический MakeHuman hm08, CC0, с отдельными мужскими и женскими формами, корректной геометрией лица, глаз и тела. Мужчина — с открытым торсом и в тренировочных шортах; женщина — в спортивном топе и шортах. Поворот перетаскиванием/клавишами, без экранных стрелок и кнопки «Спереди». Это приблизительная игровая модель, а не скан тела. Первые семь уровней сохраняют одинаковую нетренированную форму, изменения становятся постепенными с восьмого и достигают полного игрового облика к шестидесятому. Рост/вес мягко влияют на силуэт. Вымышленных баллов силы/выносливости нет. Рендер происходит по изменениям, без постоянного фонового цикла. Происхождение и лицензия: [assets/human/SOURCE.md](assets/human/SOURCE.md).

Текущие награды:

- Разминка, душ, завтрак: по 5 XP; чтение: 10 XP; полный базовый набор: ещё 20 XP.
- Свои планы: небольшое / обычное / большое — 5 / 10 / 20 XP. Не влияют на бонус за базовые дела.
- Бег: 10 XP/км; только время — 0.5 XP/мин. Темп выводится при наличии обоих значений.
- Отжимания/приседания: 0.1 XP за повторение; подтягивания: 0.5 XP за повторение.
- Футбол: 1 XP/мин, без повторной награды за расстояние.
- Зал: несколько групп мышц и упражнений за занятие; XP = 2 × подходы + вес × подходы × повторения / 100, суммируется по упражнениям.
- Цена каждого перехода растёт парами: 100, 100, 200, 200, 300, 300 XP и далее. Общий опыт суммируется: уровни 2/3/4/5 открываются при 100/200/400/600 XP; уровень 20 — при 10000 XP. Уже заработанные очки сохраняются, уровень пересчитывается по этой шкале.

История: полоса дней с отметками, переход по неделям, выбор даты и режим «Все даты», фильтры занятий/дел/планов. Запись задним числом сразу показывает соответствующий день. При смене местного дня календарь и ежедневные дела обновляются.

Прогресс: число занятий по дням недели, суммарные километры бега и известные минуты бега/игры, весовой объём зала и подходы по мышечным группам. Личные результаты: лучшие подходы домашних упражнений и наибольшие записанные веса/объёмы каждого упражнения в зале.

Достижения: 22 однократные награды в категориях «Бег», «Силовые», «Привычки». Включают 10/50/100/500 км суммарно и 5/10 км, полумарафон (21,0975 км), марафон (42,195 км) за одну пробежку. Силовые: жим штанги лёжа 40/60/80/100 кг, присед со штангой 60/100 кг, 10/15 подтягиваний и 50 отжиманий за подход, 1000 отжиманий суммарно, 5 занятий в зале. Сохранены прежние достижения первой тренировки, полного дня и серии 10 дней. Награды 10–150 XP; каталог в `progress.js`. На экране сначала шесть карточек, остальные раскрываются кнопкой, доступны категории и полосы прогресса. Недельных квестов нет.

Достижения считаются по реальным записям, без расчётного одноповторного максимума. Для силовых нужен явный вид упражнения, например «Жим штанги лёжа» / «Присед со штангой»; просто «Жим», гантели, тренажёры и наклонный жим не открывают рекорд жима штанги лёжа. Вес штанги указывается вместе с блинами. Серия дней считает дела/планы/занятия, а не получение награды.

## Сохранение и публикация

Записи остаются в localStorage `my-character-v2`. Старые фиксированные награды тренировок, прежние награды дел/планов и весь заработанный опыт сохранены. Новые уменьшенные награды дел/планов помечены `rewardVersion:2`. Старые одиночные записи зала остаются читаемыми. Достижения по уже имеющимся записям могут начислиться после обновления.

GitHub Actions: `npm ci` → тесты → сборка `_site` → Pages. Сборка включает бинарные модели, глаза, JS и лицензии. Исходные OBJ/morph target файлы, тесты, сервер, документы и данные посетителей не публикуются в `_site`.

Для регенерации геометрии из локальных оригиналов (только при изменении модели): `python3 scripts/prepare-human.py`, затем `npm test` и `npm run build`. В setup это не требуется: бинарные модели закоммичены. Проверки SHA256 оригиналов и максимальных рёбер защищают от повреждённых данных и растянутых треугольников.

Ссылкой можно делиться; у каждого посетителя отдельный локальный дневник. Общих аккаунтов/рейтинга/синхронизации пока нет. Telegram SDK поддержан, но бот ещё не настроен; initDataUnsafe не используется для авторизации. Garmin, тренер/чат с ИИ, питание и нормативы пока не реализованы.
