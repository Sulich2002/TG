# Мой персонаж

Мобильное приложение с персонажем, повседневными делами и дневником тренировок. Задумка — [CONCEPT.md](CONCEPT.md). Сайт: https://sulich2002.github.io/TG/

## Разработка

Node.js 22+ (CI — 24), фиксированный Three.js 0.180.0. Модули и анатомические модели поставляются с сайтом, без внешних CDN.

```sh
npm ci
npm start
```

`npm start` собирает `_site` и запускает порт 3000; другой порт: `PORT=3001 npm start`.

```sh
npm test
npm run build
```

54 Node-теста и 25 Python-тестов: опыт и уровни, миграция, планы, темп, тренировки/рекорды, профиль, календарные границы, серии дней, достижения и целостность моделей. Chromium дополнительно проверяет создание профиля, мужскую/женскую 3D-модель и вращение, календарь и фильтры, недельные объёмы, сохранение и все пять разделов на ширинах 320/375/390/430. Это не проверка на физическом iPhone или в реальном Telegram.

## Версия 0.4

При первом входе обязательно создаётся профиль: мужской/женский персонаж, имя, возраст, рост, вес. Данные хранятся отдельно в localStorage `my-character-profile-v1`; их редактирование не сбрасывает опыт или историю.

Модель — анатомический MakeHuman hm08, CC0, с отдельными мужскими и женскими формами, корректной геометрией лица, глаз и тела. Мужчина — с открытым торсом и в тренировочных шортах; женщина — в спортивном топе и шортах. Поворот перетаскиванием/клавишами, без экранных стрелок и кнопки «Спереди». Это приблизительная игровая модель, а не скан тела. Первые семь уровней сохраняют одинаковую нетренированную форму, изменения становятся постепенными с восьмого и достигают полного игрового облика к шестидесятому. Рост/вес мягко влияют на силуэт. Вымышленных баллов силы/выносливости нет. Рендер происходит по изменениям, без постоянного фонового цикла. Происхождение и лицензия: [assets/human/SOURCE.md](assets/human/SOURCE.md).

Текущие награды:

- Разминка, душ, завтрак: по 5 XP; чтение: 10 XP; полный базовый набор: ещё 20 XP.
- Свои планы: небольшое / обычное / большое — 5 / 10 / 20 XP. Не влияют на бонус за базовые дела.
- Бег: 10 XP/км; только время — 0.5 XP/мин. Темп выводится при наличии обоих значений.
- Отжимания/приседания: 0.1 XP за повторение; подтягивания: 0.5 XP за повторение.
- Футбол: 1 XP/мин, без повторной награды за расстояние.
- Зал: несколько групп мышц и упражнений за занятие; XP = 2 × подходы + вес × подходы × повторения / 100, суммируется по упражнениям.
- Цена каждого перехода растёт парами: 100, 100, 200, 200, 300, 300 XP и далее. Общий опыт суммируется: уровни 2/3/4/5 открываются при 100/200/400/600 XP; уровень 20 — при 10000 XP. Уже заработанные очки сохраняются, уровень пересчитывается по этой шкале.

История: полоса дней с отметками, переход по неделям, выбор даты и режим «Все даты», фильтры занятий/дел/планов. Запись задним числом сразу показывает соответствующий день. При смене местного дня календарь и ежедневные дела обновляются.

Прогресс: число занятий по дням недели, суммарные километры бега и известные минуты бега/игры, весовой объём зала и подходы по мышечным группам. Личные результаты: лучшие подходы домашних упражнений и наибольшие записанные веса/объёмы каждого упражнения в зале.

Достижения: 22 однократные награды в категориях «Бег», «Силовые», «Привычки». Включают 10/50/100/500 км суммарно и 5/10 км, полумарафон (21,0975 км), марафон (42,195 км) за одну пробежку. Силовые: жим штанги лёжа 40/60/80/100 кг, присед со штангой 60/100 кг, 10/15 подтягиваний и 50 отжиманий за подход, 1000 отжиманий суммарно, 5 занятий в зале. Сохранены прежние достижения первой тренировки, полного дня и серии 10 дней. Награды 10–150 XP; каталог в `progress.js`. На экране сначала шесть карточек, остальные раскрываются кнопкой, доступны категории и полосы прогресса. Недельных квестов нет.

Достижения считаются по реальным записям, без расчётного одноповторного максимума. Для силовых нужен явный вид упражнения, например «Жим штанги лёжа» / «Присед со штангой»; просто «Жим», гантели, тренажёры и наклонный жим не открывают рекорд жима штанги лёжа. Вес штанги указывается вместе с блинами. Серия дней считает дела/планы/занятия, а не получение награды.

## Сохранение и публикация

Записи остаются в localStorage `my-character-v2`. Старые фиксированные награды тренировок, прежние награды дел/планов и весь заработанный опыт сохранены. Новые уменьшенные награды дел/планов помечены `rewardVersion:2`. Старые одиночные записи зала остаются читаемыми. Достижения по уже имеющимся записям могут начислиться после обновления.

GitHub Actions: `npm ci` → тесты → сборка `_site` → Pages. Сборка включает бинарные модели, глаза, JS и лицензии. Исходные OBJ/morph target файлы, тесты, Node dev-сервер, документы и данные посетителей не публикуются в `_site`. `garmin-setup.sh` намеренно содержит исходный код отдельного коннектора для установки владельцем, без пользовательских данных и секретов.

Для регенерации геометрии из локальных оригиналов (только при изменении модели): `python3 scripts/prepare-human.py`, затем `npm test` и `npm run build`. В setup это не требуется: бинарные модели закоммичены. Проверки SHA256 оригиналов и максимальных рёбер защищают от повреждённых данных и растянутых треугольников.

Без входа каждый посетитель ведёт локальный дневник. В версии 0.8 доступны аккаунты, серверное сохранение и рейтинг закрытой группы друзей за текущую неделю и месяц: [docs/friends.md](docs/friends.md). Telegram SDK поддержан, но бот ещё не настроен; initDataUnsafe не используется для авторизации. Пользователь подтвердил получение Garmin-данных после установки на свой сервер; новые серверные функции требуют обновления коннектора. Тренер/чат с ИИ подготовлен в версии 0.11 и требует отдельного ключа бесплатного провайдера. Питание и нормативы пока не реализованы.

## Версия 0.6.0: Garmin

Персональный серверный коннектор: прямой вход/MFA в Garmin через `garminconnect==0.3.18`, изолированный Python 3.12.14, SQLite вне сайта, отдельный пользователь systemd, защищённый API на loopback и Cloudflare Quick Tunnel для HTTPS без домена и без изменений портов VPN. Пароль Garmin вводится только в терминале и не сохраняется; сессия хранится с правами 0600/0700. Приложение использует отдельный пароль подключения и 30-дневную отзываемую сессию.

В разделе «Занятие» — подключение Garmin-сервиса, выбор первых записей, ручная проверка похожих дублей, отключение. Дневник импортирует занятия всех типов с известными дистанцией или временем. Бег и футбол дают XP по существующим правилам; остальные сохраняются как занятия Garmin без XP за объём и не превращаются в пробежки или вымышленные силовые подходы. Дистанция, время, темп, средний/максимальный пульс, график фактически доступных измерений, движущееся/полное время. Идентификатор Garmin предотвращает повторные XP; последующие изменения уже импортированной записи не перезаписывают дневник автоматически.

Первый опрос — последние пять занятий; последующие — последние 20 активностей раз в 15 минут. Первые записи пользователь выбирает явно, последующие новые занятия за дату подключения и позднее можно добавлять автоматически при открытии сайта и раз в 5 минут, пока он виден. Старые/похожие на ручные записи требуют просмотра. Дневник по-прежнему локальный; отдельная общая база дневника и синхронизация пользовательских планов между устройствами не реализованы.

На экране «Сегодня», после подключения: сон и фазы/оценка Garmin, пульс в покое, шаги, стресс, Body Battery либо явно подписанный дневной пик, ночной HRV. Сервер запрашивает сегодня/вчера раз в час (календарь Europe/Moscow), хранит историю и отдаёт последние семь накопленных дней. Пропуски остаются пустыми; 0 шагов или стресса остаётся нулём. Эти данные не дают XP. Поддержка зависит от модели часов, их ношения и синхронизации с Connect; это измерения и оценки Garmin. Часть недоступных разделов помечается, ранее загруженные значения сохраняются с предупреждением. Браузер хранит копию для просмотра при временной недоступности сервиса; при отключении эта копия удаляется, импортированные занятия остаются.

```sh
python3 -m unittest discover -s backend/garmin -p 'test_*.py' -v
```

`npm run build` также создаёт проверяемый самостоятельный `garmin-setup.sh`: исходники внутри с SHA256, зависимости с hash-lock, `uv==0.13.1` и `cloudflared==2026.10.0` с опубликованными SHA256. Проверены установка изолированного Python и пакетов, реальный локальный HTTP API/SQLite, авторизация/Origin/отзыв/ограничение попыток, Node-импорт, мобильный интерфейс на тестовых ответах, проверка/повторная распаковка/порча установщика. Пользователь выполнил первоначальную установку на Ubuntu 22.04 и подтвердил получение Garmin-данных через туннель. Новые версии коннектора применяются владельцем через `--update`; SSH из облачной среды остаётся недоступным. Инструкции, ограничения и команды — [docs/garmin.md](docs/garmin.md).


## Версии 0.7–0.8: разбор Garmin и друзья

«Прогресс → Garmin»: графики сна, пульса в покое, шагов, Body Battery, стресса и HRV, периоды 2/3/7/30 дней, средние и сравнения с честным учётом пропусков. Месячный график листается вбок и открывается у выбранного дня. Расчёты выполняются без ИИ. В актуальном коннекторе тренировки и ежедневные показатели проверяются раз в 15 минут, сервер отдаёт до 30 накопленных дней. Быстрое обновление `garmin-setup.sh --update` сохраняет сессии и работающий туннель, не меняет VPN.

«Прогресс → Друзья»: владелец создаёт группу, приглашает друзей ссылкой, каждый создаёт отдельный аккаунт. Рейтинг по XP текущей календарной недели (с понедельника) и текущего месяца (с первого числа), Europe/Moscow. Личные профили/дневники сохраняются в отдельных записях SQLite, публичны внутри группы только имя, уровень и XP периода. Ревизии защищают от перезаписывания между устройствами; есть объединение записей и локальные резервные копии. Авторизация аккаунтов отделена от доступа к личному Garmin. Подробности запуска и ограничений: [docs/friends.md](docs/friends.md).


## Версия 0.9: личные часы Garmin

Участники группы подключают свои часы прямо из аккаунта приложения: email/пароль Garmin и код MFA при запросе, без ручного URL API и отдельного пароля сервиса. На сервере — отдельные хранилища и сессии, защищённые операции входа, очередь опроса и межпроцессная блокировка. Исходное подключение владельца сохраняется. Один Garmin не привязывается к двум аккаунтам приложения. Пароли не сохраняются; API не возвращает чужие данные или полные upstream-ошибки. Анонимное прежнее подключение владельца поддерживается. Реальная проверка входа друга в Garmin выполняется владельцем/другом после обновления; автоматические проверки используют тестовый провайдер.

ИИ рассматривается только с бесплатной квотой, по выбору пользователя. Платные API не подключены; бесплатный внешний ИИ также пока не активирован. Подтверждение условий и ключ доступа к бесплатному сервису остаются отдельным шагом. Персонаж и авторизация через Telegram не изменялись.


## Версия 0.10: свои привычки и плавание

«Сегодня → Привычки → Настроить»: добавление ежедневных привычек с наградой 5 или 10 XP, удаление из активного списка и восстановление. Название и награда сохраняются в выполненной записи; удаление не стирает историю или XP. Пустой набор не даёт бонуса. Полный активный набор даёт 20 XP один раз за день: последующие изменения списка сохраняют полученный бонус. На следующий день привычки снова доступны. Старые записи и их награды не меняются; объединение устройств не удваивает выполнения исходных привычек или дневной бонус. Определения синхронизируются вместе с дневником; удаления сохраняются как архивные записи.

«Занятие → Плавание»: обязательное время без длинных перерывов, необязательная дистанция в метрах. 1 XP за минуту, дистанция не начисляет опыт повторно. История показывает темп на 100 м при наличии обоих значений; прогресс — суммарные метры, минуты, число занятий и наибольшую дистанцию. Бассейн и открытая вода из Garmin распознаются как плавание; при наличии берётся время в движении. Уже импортированные раньше занятия сохраняют прежний вид и XP, повторного начисления нет.

Для сохранения новых привычек и плавания в аккаунте требуется обновить серверный коннектор через `--update`. Приложение проверяет поддержку: со старым сервером новые записи остаются локально, без отправки неподдерживаемого дневника. База аккаунтов, прежний Garmin и VPN при обновлении сохраняются.


## Версия 0.11: личный чат с тренером

«Сегодня → Обсудить с тренером» и «Прогресс → Тренер»: цель с датой события, выбор занятия за 7/30 дней, обсуждение прямо из истории, вопросы о нагрузке и подготовке. Сервер формирует контекст из личного дневника и доступных показателей Garmin, сохраняет разговор отдельно для каждого аккаунта. Открытие чата не отправляет данные ИИ; для отправки нужно личное разрешение участника. Пароли/ключи/чужие данные не входят в контекст. Пропуски, неизвестные группы мышц и возможные дубли отмечаются явно.

Подготовлено подключение к Groq по ключу бесплатного аккаунта, без переключения на платный сервис при исчерпании квоты. Ключ настраивает владелец внутри приложения после обновления коннектора. Дополнительные Python-пакеты и локальная модель не нужны. Сетевые ошибки сохраняют текст, повторная отправка не дублирует сохранённый ответ. 20 запросов на человека / 100 на сервер за день — собственные пределы приложения; внешний бесплатный тариф может ограничить раньше. Проверены сервер и интерфейс с тестовым провайдером; настоящий ответ ожидает действующего ключа. Инструкции, данные и ограничения: [docs/coach.md](docs/coach.md).


## Версия 0.11.1: оформление и прокрутка

Главная: свои планы расположены перед ссылкой на тренера; повторная кнопка записи тренировки убрана. Для занятий остаётся нижняя вкладка «Занятие». Кнопки, выделения и основные карточки получили спокойный мятный акцент, более мягкие формы и заметное состояние фокуса. В тренере общий режим подписан «Общий вопрос тренеру».

Разговор прокручивается вместе со страницей: отдельная область прокрутки и принудительное перемещение к ответу удалены. Обновление истории не пересоздаёт прежние сообщения, если к ним только добавился ответ, чтобы не сбивать чтение. Профиль с возрастом, ростом и весом остаётся доступен для контекста ИИ при разрешённой передаче данных. Обновление интерфейса не требует обновления серверного коннектора.
