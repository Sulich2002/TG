# Публикация Mini App

Готов workflow `.github/workflows/pages.yml`: при отправке кода в `main` он запускает тесты, собирает четыре статических файла и публикует их через GitHub Pages. Сервер Node.js на хостинге не нужен.

В репозитории необходимо один раз включить Pages с источником **GitHub Actions** (Settings → Pages → Build and deployment → Source). Это можно сделать через GitHub API, если у среды есть доступ к api.github.com и достаточные права. Наличие Git-доступа не доказывает доступ к API.

После включения Pages запустите workflow **Publish Mini App** в Actions, если предыдущий запуск уже завершился ошибкой из-за отсутствия настроек Pages. Успешный шаг Publish вернёт фактическую ссылку сайта. Не считать адрес опубликованным до успешного запуска и проверки HTTP/браузером.

HTML использует относительные ссылки на файлы и поддерживает размещение в подпапке репозитория. Публикуются только index.html, style.css, app.js и progress.js: документация и локальные пользовательские данные не входят в сайт.

Затем адрес HTTPS можно настроить у Telegram-бота в BotFather как Mini App или кнопку меню. Для локальной разработки токен бота не нужен.
