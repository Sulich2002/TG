# Публикация Mini App

Публичный адрес: https://sulich2002.github.io/TG/

GitHub Pages уже включён, источник — **GitHub Actions**. `.github/workflows/pages.yml` публикует изменения `main` и поддерживает ручной запуск.

Последовательность: checkout → Node 24 → `npm ci` → `npm test` → `npm run build` → upload `_site` → deploy Pages. Сборка включает приложение, модули Three.js и его лицензию. В сайт не попадают сервер, тесты, документация, локальные данные и node_modules.

Исходный код в HTML и JS использует относительные ссылки для подпапки `/TG/`. После успешного шага Publish необходимо проверить HTTPS-страницу и что её файлы совпадают с собранным сайтом. Сохранение облачного черновика и публикация самого сайта — разные операции.

GitHub API и проверка сайта требуют api.github.com и sulich2002.github.io. Git push сам по себе не доказывает доступ к API. Не отключать проверку TLS при проблемах с доверием браузера облачной машины к сетевому прокси: использовать curl с существующим доверенным CA и сравнение файлов либо исправить доверие браузера поддерживаемым способом.

Для Telegram адрес настраивается у бота в BotFather; сайт сам по себе не создаёт бота и не включает аккаунты. Для общего рейтинга нужен отдельный сервер и проверка Telegram initData; GitHub Pages не выполняет серверный код.
