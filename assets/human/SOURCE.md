# Anatomical model provenance

MakeHuman Community hm08 base mesh, adult male/female macro targets, low-poly eyes and brown eye texture. Assets are CC0 1.0 (see source/LICENSE.ASSETS.md and asset headers). Downloaded from https://github.com/makehumancommunity/makehuman on 2026-10-15. Upstream code is not included.

`source` retains original files. `scripts/prepare-human.py` builds local binary geometry. Only `model`, brown_eye.png, SOURCE.md and the asset license are deployed. The runtime adapts body shape for game levels and profile choices; it is an approximation, not a scan or medical assessment.
