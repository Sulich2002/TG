# Garmin Connect — личный сервер

Код коннектора, защищённого API и интерфейса готов. Реальный аккаунт владельца ещё не подключён: SSH из облачной среды не проходит. Владелец вошёл через терминал HostVDS и подтвердил Ubuntu 22.04.4 LTS. SSH слушает 22, UFW отсутствует; это не доказывает отсутствия остальных сетевых фильтров. IP добавлен и опубликован в настройках среды, но прокси всё равно возвращает Domain forbidden. Не повторять бесконечно публикацию и не менять настройки работающего VPN, чтобы обойти ограничение облачной среды.

IP, адрес панели и присланные пользователем секреты не записывать в исходники или журналы и не воспроизводить. Пароли вводятся владельцем только в терминале/форме назначения. Настройки Telegram-бота и общего рейтинга остаются отдельной задачей.

## Установка в терминале root на Ubuntu 22.04

```sh
curl -fsSL https://sulich2002.github.io/TG/garmin-setup.sh -o /tmp/tg-garmin-setup.sh && bash /tmp/tg-garmin-setup.sh
```

Сначала публикуется версия сайта с установщиком; пользователь выполняет команду в своём уже открытом терминале HostVDS. Это установка, а не диагностическая команда. Не запускать её из чата с паролями в аргументах. Скачивание по HTTPS с проверкой сертификата, выполнение только после успешного скачивания; `curl | bash` не используется.

Установщик проверяет свободное место и loopback-порт 8765, проверяет SHA256 встроенного архива исходников и извлекает только разрешённые файлы. Добавляет системные `ca-certificates`, `curl`, `python3-venv`, изолированный Python 3.12.14 через закреплённый uv и hash-locked зависимости, проверенный cloudflared. ОС и системный Python не обновляются на другую версию. Отдельный `/opt/tg-garmin`, данные `/var/lib/tg-garmin` (0700), пользователь `tg-garmin`, команда `/usr/local/bin/tg-garmin`. Создаются только свои три службы и таймер systemd; службы/файрвол/порты VPN, SSH и панель не перенастраиваются. Используется исходящее соединение Cloudflare, входящие порты не открываются. Требуется около 700 МБ свободного места; лимиты памяти служб заданы отдельно, полную нагрузку рядом с VPN нужно проверить на сервере владельца.

В конце — интерактивный вход в Garmin: email, скрытый пароль, при необходимости MFA. Затем отдельный пароль приложения (12–200 символов, дважды); не пароль root/панели. Garmin-пароль не сохраняется; токены хранятся в закрытом каталоге. Сервис привязывается к владельцу, другой аккаунт не смешивается с имеющимися данными. Первые пять занятий и доступные ежедневные данные за сегодня/вчера загружаются после входа. Только после успешной настройки включаются API, туннель и таймер.

Если настройка прервалась после установки файлов, повторный вход:

```sh
tg-garmin connect
```

Пароли не видны при вводе. Не просить снимок экрана во время ввода или копирование секретов в чат. Ошибки upstream не выводятся целиком: они могут содержать ответы и данные аккаунта.

## Подключение телефона

Через минуту:

```sh
tg-garmin status
```

Команда показывает только число записей, время/состояние и HTTPS-адрес вида `https://…trycloudflare.com`; паролей и токенов не показывает. В приложении → «Занятие» → Garmin Connect → «Подключить»: этот адрес и отдельный пароль приложения. Выбрать первые занятия, затем сохранить выбор и режим автоматического добавления. Похожие на ручные записи по дате/типу/дистанции либо времени не выбираются автоматически. На повторном опросе известные Garmin activity ID не дают XP ещё раз.

Garmin опрашивается раз в 15 минут, ежедневные данные — раз в час. Телефон получает новые записи при открытии сайта и раз в 5 минут, пока он видим. Это не мгновенный webhook. Часы сначала должны синхронизироваться с Connect. При закрытом сайте локальный дневник обновится при следующем открытии. Сервер сохраняет/обновляет исходные записи, уже импортированная в дневник запись автоматически не перезаписывается; существующие XP сохраняются. Ограниченный опрос: после начальных пяти опрашиваются последние 20 активностей, глубокая историческая загрузка пока не реализована.

В дневник добавляются все типы занятий с известным временем или расстоянием. Для бега и футбола (`soccer`) рассчитывается XP. Другие виды сохраняются отдельными занятиями Garmin с исходным названием, временем/дистанцией/пульсом и нулевым XP за объём; они не подменяются бегом или вымышленными силовыми подходами. Достижение первой реальной тренировки по-прежнему может открыться для такого занятия. Пульс: фактические средний/максимальный и до 300 исходных точек графика, длительности движения/с паузами. Сон: длительность, фазы, оценка Garmin. Ежедневно: пульс в покое/минимум/максимум, шаги, средний стресс, Body Battery (если нет текущего — отдельно подписанный пик), ночной HRV. Нули/пропуски различаются; никаких норм, диагнозов, дополнительных XP или искусственно заполненных значений.

Календарь сервера — Europe/Moscow. Сегодня/вчера обновляются раз в час, UI показывает последние семь накопленных дней; первоначально доступны только два дня. Исходные подробные ежедневные ответы старше 30 дней удаляются из SQLite, нормализованные значения сохраняются. Отсутствующий показатель может не поддерживаться часами или ещё не быть загружен. При ошибке отдельного раздела сохраняются ранее доступные данные и предупреждение. В браузере есть локальный кеш ежедневных данных; после отключения он удаляется. Журнал тренировок и профиль остаются локальными, общая синхронизация дневника между устройствами пока не реализована.

## Разбор показателей в приложении

«Прогресс → Garmin»: шесть показателей, график за последние семь календарных дней, среднее/минимум/максимум и подробности выбранной даты. Карточки Garmin на экране «Сегодня» открывают нужный показатель. Пропуски и разделы с ошибкой обновления исключаются из расчётов, реальные нули сохраняются. Сегодняшние шаги, средний стресс и пик Body Battery показываются как предварительные и не входят в среднее/экстремумы завершённых дней. Для Body Battery сравниваются только дневные пики, текущий заряд подписан отдельно. Изменение среднего сравнивает первые три и следующие три дня окна, только при наличии всех шести значений; сегодня исключён. Ночной сон/HRV за текущую дату учитываются как завершённая ночь.

Расчёты выполняются в браузере без ИИ, API-ключей, советов и передачи данных дополнительному сервису. Первые два дня не представляются полной неделей. Обновление интерфейса не требует переустановки серверного коннектора.

## Доступ и ограничения

API слушает только `127.0.0.1:8765`. HTTPS предоставляет Cloudflare Quick Tunnel; Cloudflare участвует в передаче данных, отдельная подписка и домен не нужны. Quick Tunnel — временный адрес без SLA: он может измениться при перезапуске. Тогда выполнить `tg-garmin status` и заменить адрес подключения в приложении. Долговременный адрес требует отдельно настроенного домена/именованного туннеля. Не обещать вечную бесплатность стороннего сервиса.

`/healthz` возвращает только имя/версию службы. Остальные данные требуют bearer-сессию; пароль подключения хранится PBKDF2 SHA256 с солью, сессии — хешами, срок 30 дней, доступен отзыв. Восемь попыток входа в минуту, ограничение размера тела и параллельных соединений, no-store, фиксированный Origin сайта. Garmin-пароль по веб-API не принимается. API не отдаёт сырые ответы/GPS-маршруты; они остаются в закрытой SQLite. Секреты не передаются в URL и не пишутся в логи. TLS-проверку не отключать.

[python-garminconnect](https://github.com/cyberjunky/python-garminconnect) 0.3.18 (MIT), `curl-cffi` и зависимости закреплены с SHA256. Неофициальный доступ: изменения Garmin могут нарушить вход, при истечении/отзыве сессии нужен повторный вход и иногда MFA. Ограничения запросов вызывают отложенную повторную попытку, а не частые повторные логины. При смене аккаунта повторный вход блокирует смешение записей.

```sh
tg-garmin disconnect
```

Останавливает свой таймер, удаляет локальную Garmin-сессию и отзывает сессии приложения; данные остаются на сервере и в дневнике. Удаление локального токена не является отзывом уже выпущенного токена у Garmin. При подозрении на утечку доступ отзывается в настройках Garmin. Работающий VPN не меняется.

## Проверки и состояние

42 Node-теста, 9 Python-тестов; установка закреплённых uv/Python/Garmin-пакетов в изолированные временные каталоги; SHA256 бинарника cloudflared сопоставлен с официальным релизом 2026.10.0. Реальный локальный HTTP API/SQLite проверен на тестовых данных: вход, Origin, сессия, отзыв, лимиты, источник данных, обновление без дублей, ежедневные значения/фазы, пропуски, привязка аккаунта. Установщик: bash/shellcheck, проверки контрольной суммы и повторной распаковки, отказ от символьных ссылок. Chromium проверяет экран подключения/выбор/дубли/импорт/повторное открытие/автоматическое добавление/пульс/сон и мобильные ширины 320/375/430 на подставленных тестовых ответах.

Пользователь выполнил установку на HostVDS и подтвердил получение тренировок и ежедневных показателей в приложении. Автоматические проверки используют тестовые данные; независимая проверка VPN и состояния systemd на пользовательском сервере не выполнялась.
