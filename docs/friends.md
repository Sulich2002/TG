# Друзья и рейтинг

Раздел «Прогресс → Друзья». Поддерживается одна закрытая группа на личном сервере (до 200 аккаунтов). Дополнительные сервисы, оплата API и Telegram bot token не нужны. Это обычные аккаунты приложения, а не подтверждённые Telegram-аккаунты. Для размещения непосредственно в меню Mini App по-прежнему нужен отдельно настроенный Telegram-бот.

## Запуск

Обновить уже установленный коннектор, сохраняя данные Garmin, сессии приложения, адрес туннеля и VPN:

```sh
curl -fsSL https://sulich2002.github.io/TG/garmin-setup.sh -o /tmp/tg-garmin-update.sh && bash /tmp/tg-garmin-update.sh --update
```

После успешного обновления открыть сайт → «Прогресс → Друзья → Создать группу друзей». На устройстве владельца должно быть рабочее подключение к его Garmin-сервису: оно подтверждает право создать группу. Указать отдельные логин и пароль аккаунта. Текущий персонаж и дневник переносятся в аккаунт. Начальный опыт раннего прототипа сохраняет общий уровень, но не участвует в недельном/месячном рейтинге.

Нажать «Пригласить друзей» и отправить скопированную ссылку. Друг создаёт персонажа, затем аккаунт (имя персонажа, логин, отдельный пароль). Адрес сервера и приглашение подставляются автоматически. Приглашение в URL-фрагменте даёт право регистрации, не входа в чужой аккаунт, и не содержит пароль/токен Garmin. Не публиковать реальные личные приглашения в репозитории. При повторном входе на другом устройстве нужны адрес сервера, логин и пароль. Восстановление забытого пароля пока не реализовано.

## Подсчёт и данные

Календарь — Europe/Moscow: текущая неделя с понедельника, текущий месяц с первого числа, по дату сегодня включительно. Считается XP записей за даты занятий/дел и даты выдачи достижений, плюс дневные бонусы за полный набор привычек (включая сохранённые прежние базовые наборы). Сервер сам считает XP по действующим/сохранённым версиям правил и проверяет условия достижений; переданное клиентом поле XP не используется как оценка. Записи вручную остаются самоотчётом, независимой проверки выполнения упражнений нет. При равном XP — одинаковое место (1, 1, 3). В начале нового периода общий уровень не обнуляется.

Серверная таблица `friend_accounts` хранит профиль и личный дневник; другие участники получают только ID, имя, уровень, место и XP периода. Личные данные Garmin доступны через защищённые маршруты своего аккаунта. Токен аккаунта не открывает корневой `/v1/activities`, Garmin-токен не открывает чужой дневник. Владелец группы также не получает чужие пароли или дневники через API. Администратор сервера технически имеет доступ к своей SQLite, как и к остальным данным на своём сервере.

Пароли аккаунтов — PBKDF2 SHA256 с уникальной солью (600000 итераций), bearer-сессии — только SHA256-хеши, срок 30 дней. Приглашение хранится хешем на сервере; владельцу доступен выпуск нового кода, старый после перевыпуска недействителен. Создание группы/регистрация/вход ограничены общим бюджетом попыток. Запросы только по HTTPS через существующий туннель, с фиксированным CORS Origin сайта. Логи не содержат паролей и токенов.

Изменения сначала сохраняются локально, затем отправляются на сервер. Номер ревизии защищает от молчаливого перезаписывания другим устройством. При конфликте можно объединить записи по ID (локальная версия совпадающего ID имеет приоритет) либо загрузить серверную копию; локальная копия остаётся в резерве. Планы объединяются по ID, начальный опыт берётся по максимуму и не суммируется дважды. При выходе несохранённые записи остаются в отдельном локальном кеше этого аккаунта и восстанавливаются при повторном входе. На другом устройстве доступна только последняя успешно отправленная версия.

Случайный адрес Cloudflare Quick Tunnel может измениться после перезапуска туннеля. Постоянный адрес требует отдельного домена/именованного туннеля. Текущее обновление не перезапускает туннель.

## Проверка

46 Node-тестов и 18 Python-тестов, в том числе соответствие серверного расчёта XP фронтенду, HTTP-сессии двух пользователей, права доступа Garmin/аккаунтов, календарные границы рейтингов, одинаковые места, конфликт ревизий, выход, отказ поддельным XP и невозможным достижениям. Chromium с реальным локальным Python API: создание группы, приглашение нового пользователя с нуля, автоматическая синхронизация, рейтинг двух аккаунтов, вход с третьего устройства, конфликт и объединение, выход и ширины 320/375/430. Это проверка на тестовых данных, а не подтверждение установки новой версии на пользовательском сервере.

## Личные часы

После входа в аккаунт → «Занятие → Подключить Garmin»: свой email/пароль Garmin и при необходимости код подтверждения. Друзьям не нужны терминал, личный VPS, адрес API или пароль Garmin владельца. Текущий URL сервера берётся из аккаунта приложения. Предварительное обновление коннектора выполняет только владелец сервера. Подробности и ограничения — [garmin.md](garmin.md).

С версии 0.10 дневник включает настраиваемые ежедневные привычки и плавание (1 XP/мин). Удаление привычки убирает её из списка, но сохраняет выполненные записи и XP. Для этих записей нужен обновлённый коннектор: приложение проверяет поддержку через `/v2/me` и сохраняет изменения локально, пока старый сервер не обновлён. Объединение устройств сопоставляет привычки по ID и времени изменения, сохраняет удаления и не удваивает выполнения исходных привычек и бонусы за день.
